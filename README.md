# Google Drive para Nelkano

Módulo opcional para guardar y recuperar juegos, partidas y portadas en tu propio Google Drive.

## Versión 0.1.0

[Descargar Drive.nelkmod](https://raw.githubusercontent.com/ivanpg94/drive/main/releases/0.1.0/Drive.nelkmod)

Importa el paquete desde Ajustes → Módulos en Nelkano y conecta tu cuenta de Google.

SHA-256: `f44ea44d22d9b12e0a152dcbaa436398c3f86880734f297f0cf8f4f421d79609`.

Este repositorio distribuye el módulo firmado.
