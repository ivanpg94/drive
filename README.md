# Google Drive para Nelkano

Módulo opcional para guardar y recuperar juegos, partidas y portadas en tu propio Google Drive.

## Versión 0.1.2

[Descargar Drive.nelkmod](https://raw.githubusercontent.com/ivanpg94/drive/main/releases/0.1.2/Drive.nelkmod)

Corrige el retorno de la conexión Google en escritorio/SteamOS y conserva el flujo de Android.

En Nelkano, desactiva Drive si está activo, importa el paquete desde Ajustes → Módulos y vuelve a activarlo. Conserva sus datos y el autor original.

La persistencia de sesión en SteamOS requiere también la aplicación 3.0.6 con la corrección del almacén de credenciales.

SHA-256: `9e092e977ba820bb47051b8dbd852cf3e665e37e98279c73de5bfbafcaf021ff`.
